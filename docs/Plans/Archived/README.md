# Archived plans

Completed and cancelled execution plans may be retained here briefly for
handoff context. They are records of past work, not durable sources of product
or workflow policy.

Keep a plan only when its decision rationale is still useful and link the
implementing commit in its front matter or opening section. Otherwise delete it
after the next release; git history already preserves the record. Archived
plans must never be cited as the current behavior owner.
