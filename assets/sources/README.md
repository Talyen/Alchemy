# Alchemy asset masters

This directory contains the selected original art, sound, music and icon masters
used to prepare Alchemy's committed runtime assets. These are regular, versioned
files. Their historical folder names preserve existing manifest paths; no other
project or external library is required.

Copy approved replacements into this directory, update the owning selection under
`scripts/assets/` as needed, and run preparation and read-only source checks. Commit
masters, selections and prepared outputs together. External library changes never
update these copies. Do not replace masters with symlinks or store unused library
inventories here.

See [asset workflows](../../Docs/WORKFLOWS-ASSETS.md) for commands and ownership.
