# Test value review — October 2, 2026

This is a point-in-time portfolio review of the current checkout using [the test value policy](../CONTRIBUTING.md#test-value-and-coverage-strategy).

Later consolidations moved Upgrade node interaction protection into [Homestead screen tests](../tests/features/alchemy/meta/screens/homestead-screen.test.tsx), loot report guarantees into [loot report tests](../tests/lib/loot/report.test.ts), and report helper consumer protection into [report rendering tests](../tests/lib/balance/report-render.test.ts). Shared hook wrapper tests were later retired in favor of [Currency Chip interaction and stock feedback tests](../tests/features/alchemy/shared/ui/currency-chip.test.tsx) and existing Health animation and auto-End Turn consumer tests. Their historical inventory rows below are marked retired; the snapshot counts remain unchanged.

A subsequent quality pass retired the combat-tuning and battle-timing constant suites: their positivity and relative-price assertions constrained tuning without proving combat or playback behavior. Fight pacing, crowd-control, campfire, and turn/draw sequencing tests retain consequential outcome protection. The Mystery effect-order helper suite and its source-text switch guard were also retired; an exhaustive typed rank table owns kind coverage, while Mystery event and effect-badge tests exercise its consumers. This pass consolidated overlapping Mana, damage, and regeneration cases, strengthened nested save-effect round trips and simulator measurement parity, and added an archive preflight regression for conflicting plan metadata.

The October 4 quality pass further consolidated player Burn mitigation matrices into combined-reduction, fully absorbed damage, lethal sequencing, and ordered-feedback scenarios. A test claiming immunity expiry merely rewrote cooldown to zero; it was retired alongside a redundant below-threshold variant. The actual crowd-control guards and immunity-start tests remain in `status-cc.test.ts`, while offensive-talent isolation and cooldown suppression remain in the player-tick suite. Card-description tests now cover the shared Companion modifier contract, trailing copy, brewed labels, and conditional reaction previews instead of separate unchanged-string variants. Enemy threshold tests share one crossing between Second Wind and Divine Aegis and verify once-only activation; redundant standalone Cinder Skin and Aegis cases were removed while card, Companion, DoT, and saved-reaction paths remain.

Telemetry now has one [marks suite](../tests/lib/performance/marks.test.ts) for startup deduplication, repeated battle marks, isolated cleanup, and unavailable User Timing; the forwarding module and its duplicate suite were removed. The mocked combatant drawing suite was retired: primitive-call and palette-length assertions did not establish rendered fidelity. The [status loop suite](../tests/lib/animation/combatant-status-effect-loop.test.ts) now exercises real reduced-motion painting, and retains resize, focus, disposal, and resumption protection. Fine visual details still require rendered review; no rendering formulas changed. Leech coverage now verifies overheal Mana without restoration rewards or extra RNG, and that siphoning transfers exactly one available defense. Menu badge coverage checks that exhausted Talent trees do not advertise nonexistent choices.

## Scope and method

The inventory contains **657 test files and 5818 test declarations**, including parameterized declarations before expansion: Node and DOM units, browser and Electron E2E, dedicated balance/playthrough suites and layout-review specs. Three files whose names contain test are support helpers with no test declarations and are excluded. The existing deletion of contiguous-run and the earlier E2E retirements were already present and are not attributed to this review.

Every file was included in structural screening of test declarations and assertion bodies; suite-purpose grades below describe the dominant protection, rather than asserting every individual case in a High suite is equally valuable. Suspected low-value cases were reread in full and checked against owners, consumers, nearby protection and relevant history before deletion. Retained suites received a portfolio-level review with targeted source sampling; this is not an exhaustive line-by-line or mutation assessment of every retained assertion.

**High:** consequential outcomes, progress durability, blocked interaction, lifecycle or architectural contracts. **Medium:** real but limited/overlapping behavior or presentation/reporting contracts. **Low:** tautologies, implementation restatements, weak content snapshots or redundant checks with stronger surviving protection. Medium cases remain because the user specifically requested deletion of low-value tests.

## Disposition

- Primary suite grades before retirement: **595 High, 60 Medium, 2 Low**. Mixed suites are recorded in the retirement table. These are suite counts, not expanded runtime case counts.
- Removed **52 low-value test declarations across 26 files**, including two wholly low-value files. The Homestead declaration runs in three categories, so the removal represents 54 runtime cases. No replacement tests were added.
- Existing production and test edits were preserved. Unused test-only imports, constants and empty groups were removed. The Armory coverage index was updated.
- No browser/Electron journey was confirmed low-value in this pass. Real timing, keyboard, save and packaged-boundary journeys remain.

## Borderline protection retained

- The loading-caption font-size browser assertion is Medium, retained because [UI conventions](./UI.md) explicitly define its reference size and proportional scaling. It measures browser output.
- Tooltip motion, particle palettes, gear naming, menu badges and report formatting are Medium: limited consequences, but real behavior. This review does not apply the repository default retirement of Medium cases because the user asked for low-only deletion.
- Fixed seven-card starting decks remain High: catalog resolution can silently drop an unknown card; count and reference guards together detect an unplayable starting deck.
- Combat variant and named regression suites remain High at suite level: ordering, trigger attribution, seeded RNG and save state can give superficially similar assertions distinct protection. Shared formulas alone do not establish redundancy.
- Documentation phrase guards remain Medium because their comments identify prior semantic drift; they still protect guidance for destructive and persistence operations.
- WebGL fallback, animation fidelity and packaged Electron checks remain: mocked unit correctness cannot prove browser/GPU/packaged wiring.
