# Round 4: quieter showcase treatments

Historical review drafts. The [selected user-supplied promo](../../README.md)
is now the shipping source; these alternatives preserve the original artwork.

- [Quiet gallery](./quiet-gallery.html): removes outer gold borders, separate caption bands, statistics, and inner item frames; retains gentle image corners and captions beneath the art
- [Editorial collage](./editorial-collage.html): removes frames and uses understated captions over fading image edges

Both replace the 4×2 hero arrangement with a 3–2–3 cast mosaic. Face scale is
normalized per portrait, and the cuts are coordinated around faces instead of
splitting them. All eight heroes and seven bosses remain represented.

The recommendation at this round was to use the quiet gallery as the next baseline. Counts could live on
the Steam store page rather than competing with the artwork here. The editorial
alternative offers a more poster-like treatment but places text over illustrations.

Regenerate with `node scripts/render-demo-showcase-round4.mjs`. It uses the previous
round's editable HTML as a base, writes these editable HTML sources, and captures
review PNGs under `reports/demo-showcase-revisions/`. Library remains the approved
temporary third Homestead artwork. Neither image replaces the in-game master.
